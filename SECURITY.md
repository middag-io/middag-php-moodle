# Security Policy

## Supported versions

This library is on the `1.x` release line, versioned per the `middag-php-*`
family policy in [API-STABILITY.md](API-STABILITY.md) (mirrored in the
framework's
[API-STABILITY.md](https://github.com/middag-io/middag-php-framework/blob/main/API-STABILITY.md)).
The 1.x line is pre-stable and unsupported: it gets no backports or security fixes, and the move to 2.0.0 is a clean cut.

## Reporting a vulnerability

Please **do not** open public issues for security vulnerabilities.

Report privately through one of:

- GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  — use **"Report a vulnerability"** under the repository's **Security** tab, or
- email **michael@middag.io** with a description and steps to reproduce.

We aim to acknowledge a report within 5 business days and to share a remediation
timeline after triage. Please give us reasonable time to release a fix before any
public disclosure.
